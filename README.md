## 🏆 Unlocking the "Codebreaker" Trophy / Achievement

Opening **any 5 of these 10 locked safes or keypads** will instantly unlock the silver trophy / 30G achievement **"Codebreaker"**.

> ⚠️ **Warning — Missable Content**: *Hellraiser: Revival* does not feature an episodic chapter-select feature during standard playthroughs. If you trigger the transition cutscene past the Industrial Sector before unlocking the Laundry Room or Break Room lockers, you cannot backtrack without loading a manual save.

## 💻 CLI Quick Lookup Tool

This repository includes a lightweight Python utility to search codes by room, chapter, or loot reward directly from your terminal:

```bash
# Clone the repository
git clone https://github.com/seraseraqqq/hellraiser-revival-safe-codes.git
cd hellraiser-revival-safe-codes

# Run with Node.js
node lookup.js
node lookup.js magnum
node lookup.js sewer

# Or run with Python (if installed)
python lookup.py
python lookup.py magnum
```
